## Regression Prediction Problem

This project is part of a Kaggle Competition to predict the nightly price for AirBNBs in Jersey City (NJ), Chicago (IL), and Washington DC through the application of Machine Learning and Data Science using listing characteristics, neighborhood information, host information, and reviews. Model performance was evaluated using Mean Average Error (MAE). Project was a part of my STAT 303-3 (Data Science in R) Class.
